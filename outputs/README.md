# Generated outputs

Training checkpoints, logs, debug images, inference comparisons, videos, and
other generated artifacts are written below this directory and excluded from
Git.

Outputs are not required to run the code. Copy only experiment directories
that must be compared or resumed; avoid mirroring the entire directory by
default.
